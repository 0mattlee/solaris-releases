# SOLARIS

A desktop application for 3D modeling and game assets, by Matheus Morais.

This repository only publishes the builds of SOLARIS. The source code is private.

**[Download / Baixar: SOLARIS 0.7.0 pre-alpha](https://github.com/0mattlee/solaris-releases/releases/tag/v0.7.0-pre-alpha)** - [all builds / todas as versões](https://github.com/0mattlee/solaris-releases/releases)

## Português

O SOLARIS é um programa de modelagem 3D e criação de assets para jogos, de Matheus Morais. Este repositório só
publica as versões para download. O código-fonte é privado.

A versão atual é um **pré-alfa**, para testes: pode travar, mudar de forma incompatível entre versões e ter recursos
incompletos. Salve com frequência e mantenha cópias dos seus projetos.

### Requisitos

- Windows 10 (versão 1809 ou mais nova) ou Windows 11, 64 bits.
- Placa de vídeo com OpenGL 4.5 e driver atualizado.

### Instalar

1. Baixe `SOLARIS-0.7.0-pre-alpha-setup.exe` na página da versão.
2. Confira o arquivo: no PowerShell, na pasta do download, rode
   `Get-FileHash .\SOLARIS-0.7.0-pre-alpha-setup.exe`. O código deve ser igual ao de `SHA256.txt`, publicado junto. Se
   for diferente, não instale.
3. O instalador ainda não tem assinatura digital, então o Windows pode mostrar "O Windows protegeu o computador". Depois
   de conferir o código, clique em **Mais informações** e em **Executar assim mesmo**.
4. O instalador não pede administrador. Ele oferece atalhos e abrir arquivos `.solaris` com o SOLARIS.

### Termos de uso

Uso pessoal e não comercial, para avaliação e teste. Vender, redistribuir, usar comercialmente ou disponibilizar o

são seus. O texto completo está em [TERMS-OF-USE.txt](TERMS-OF-USE.txt) e é mostrado pelo instalador.

O SOLARIS usa componentes de terceiros, como o Qt, sob suas próprias licenças, incluídas na pasta `licenses` da
instalação.

## English

SOLARIS is a 3D modeling and game asset application by Matheus Morais. This repository only publishes its builds. The
source code is private.

The current build is a **pre-alpha**, for testing: it may crash, change incompatibly between builds and have unfinished
features. Save often and keep copies of your projects.

### Requirements

- Windows 10 (version 1809 or later) or Windows 11, 64-bit.
- A graphics card with OpenGL 4.5 and an up-to-date driver.

### Installing

1. Download `SOLARIS-0.7.0-pre-alpha-setup.exe` from the release page.
2. Check the file: in PowerShell, in the download folder, run `Get-FileHash .\SOLARIS-0.7.0-pre-alpha-setup.exe`. The
   hash must match `SHA256.txt`, published with it. If it differs, do not install.
3. The installer is not digitally signed yet, so Windows may show "Windows protected your PC". After checking the hash,
   click **More info** and then **Run anyway**.
4. The installer needs no administrator. It offers shortcuts and opening `.solaris` files with SOLARIS.
